# 19 · Glossary

Plain-English definitions, A to Z.

| Word | Meaning |
|---|---|
| **Agent** | An AI that decides which tools to use, step by step, to finish a task |
| **API** | A menu of web addresses a program offers, each doing one job |
| **API key** | A password-like string that lets your program use a service |
| **Artifact Registry** | Google Cloud's storage for Docker images |
| **async** | Python style where a function can wait without blocking others (`await`) |
| **Backend** | The part that runs on a server and does the work (Python here) |
| **Branch** | A separate line of work in Git |
| **Bucket** | A cloud folder in Cloud Storage |
| **Chunk** | A small piece of a document (about 1000 characters here) |
| **CI/CD** | A robot that builds and delivers your app automatically |
| **Cloud Build** | Google's service that builds Docker images in the cloud |
| **Cloud Run** | Google's service that runs a container, scaling to zero when idle |
| **Cloud Storage** | Google's file storage |
| **Commit** | One saved set of changes in Git |
| **Container** | A running copy of a Docker image |
| **CORS** | A browser rule about which websites may call an API |
| **Dependency** | A package written by someone else that your code uses |
| **Deployment** | Putting a new version of the app onto its cloud resources |
| **Docker / image** | A tool that packs an app and everything it needs into one sealed box |
| **Dockerfile** | The recipe for building a Docker image |
| **Embedding** | A list of numbers (768 here) capturing the meaning of a text |
| **Endpoint (API)** | One web address of the backend |
| **Endpoint (Vector Search)** | The running service that searches the index; billed by the hour |
| **Environment variable** | A named value that lives outside your code |
| **FastAPI** | A Python framework for building APIs |
| **Fork** | Your own copy of someone else's GitHub repo |
| **Frontend** | The screen part, running in the browser (React here) |
| **Gemini** | Google's AI model family |
| **GitHub Actions** | GitHub's robot that runs workflows such as `deploy.yml` |
| **Hallucination** | When an AI states something confident that isn't true |
| **IAM** | Google Cloud's system of who may do what |
| **Index (Vector Search)** | The stored data you search |
| **JSON** | Text format for data, like a Python dictionary |
| **LangChain** | A toolkit for connecting AI steps (prompts, models, tools, retrievers) |
| **LangGraph** | A library for AI workflows with loops and branches; `create_agent` uses it inside |
| **LLM** | Large language model: an AI that reads and writes text |
| **Log** | A diary the program writes while running |
| **Log level** | How serious a log line is: DEBUG, INFO, WARNING, ERROR, CRITICAL |
| **Module / package** | One Python file / a folder of them |
| **Provisioning** | Creating the cloud resources an app needs |
| **Prompt** | The instructions given to an AI |
| **Pydantic** | A library that checks data has the right shape |
| **RAG** | Look up the relevant pieces first, then answer from them |
| **React** | A library for building screens |
| **Region** | A physical location of Google's computers, e.g. `us-central1` |
| **Repository (repo)** | A project folder plus its history |
| **Retriever** | The part that returns the best matching chunks |
| **Secret Manager** | Google Cloud's safe for keys and passwords |
| **Service account** | An account for a program instead of a person |
| **Structured log** | A log line in a machine-readable format (JSON) |
| **Supervisor** | Code that runs several agents and combines their results |
| **Temperature** | How random an AI's wording is; 0 = most repeatable |
| **Terraform** | A tool that creates cloud resources from a description (not used in this project) |
| **Token** | A small chunk of text; AI pricing counts tokens |
| **Tool** | A small program an AI may choose to run |
| **Uvicorn** | The program that runs a FastAPI app |
| **Vector database** | A database that finds stored items with the most similar numbers |
| **Virtual environment** | A private box of Python and packages for one project |
| **Vite** | The tool that builds and serves the frontend |
